# Portfólio Profissional — Eduarda Flausino

## Sobre o projeto

Este projeto consiste na criação de um portfólio profissional para a disciplina
**Design Profissional**.

O portfólio apresenta informações acadêmicas, competências técnicas,
competências comportamentais, cursos, projeto desenvolvido em equipe,
currículo e links profissionais.

O site foi desenvolvido utilizando HTML5 e CSS3 e será publicado utilizando
o GitHub Pages.

---

## Objetivos

- Apresentar o perfil profissional de Eduarda Flausino.
- Apresentar sua formação em Ciência da Computação.
- Organizar competências técnicas e comportamentais.
- Apresentar cursos realizados.
- Apresentar um projeto desenvolvido em equipe.
- Disponibilizar o currículo profissional em PDF.
- Praticar a utilização do Git e GitHub.
- Publicar o portfólio utilizando o GitHub Pages.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

Não foram utilizados frameworks, bibliotecas externas ou JavaScript.
